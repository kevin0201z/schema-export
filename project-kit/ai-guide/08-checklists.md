# 检查清单

> AI 快速摘要
>
> - 适用场景：初始化、功能开发、契约变更、提交前检查、代码审查、安全核对。
> - 必须产出：命中的检查章节、未通过项、需要补充的验证或文档。
> - 硬性阻断：发现文档与代码冲突、关键契约不一致或高风险未确认时不能直接放行。
> - 相关模板：`change-summary.template.md`、`security-review.template.md`
> - 可跳过场景：极小范围文案修正时，可只使用相关局部清单。

本文档用于在项目初始化、功能开发、契约变更、提交前进行快速检查。

## 0. 按任务类型使用哪些清单

| 任务类型 | 使用清单 |
|---|---|
| 新项目初始化 | 1, 7 |
| 已有项目接入 | 7, 8 |
| 功能开发 | 2, 7 |
| API 变更 | 3, 6, 7 |
| 数据库变更 | 4, 6, 7 |
| 前端页面变更 | 5, 6, 7 |
| 代码审查或验收 | 8 |
| 安全敏感变更 | 9 |

## 1. 项目初始化检查清单

- [ ] 是否已确认项目目标？
- [ ] 是否已确认目标用户？
- [ ] 是否已确认 MVP 范围？
- [ ] 是否已确认非目标？
- [ ] 是否已判断项目类型？
- [ ] 是否已生成匹配的文档结构？
- [ ] 是否已生成 `requirements.md`？
- [ ] 是否已生成 `tasks.md`？
- [ ] 是否已生成必要的架构、UI、API、数据库文档？
- [ ] 是否已生成最小可运行项目骨架？
- [ ] 是否已验证项目可以启动或运行？

## 2. 功能开发前检查清单

- [ ] 当前任务是否来自 `docs/tasks.md`，或是否已说明任务来源？
- [ ] 是否已按任务类型读取最小阅读集？
- [ ] 是否已阅读 `docs/requirements.md` 或当前功能相关文档？
- [ ] 是否已完成功能影响分析？
- [ ] 是否明确验收标准？
- [ ] 是否判断需要更新哪些文档？
- [ ] 是否已判断风险等级？
- [ ] 如果是 `Hard Stop` 或 `Ask First`，是否已让用户确认？

## 3. API 变更检查清单

- [ ] 是否更新 `docs/api/api-spec.md`？
- [ ] 是否明确请求方法和路径？
- [ ] 是否明确请求参数或请求体？
- [ ] 是否明确响应结构？
- [ ] 是否明确错误返回？
- [ ] 是否明确权限要求？
- [ ] 前端调用是否与 API 文档一致？
- [ ] 后端实现是否与 API 文档一致？
- [ ] 是否更新相关测试？
- [ ] 是否更新 `docs/contracts/contract-map.md`？

## 4. 数据库变更检查清单

- [ ] 是否更新 `docs/database/data-model.md`？
- [ ] 是否明确表名和字段名？
- [ ] 是否明确字段类型？
- [ ] 是否明确必填、默认值、唯一约束？
- [ ] 是否明确外键关系？
- [ ] 是否明确索引？
- [ ] 是否需要迁移文件？
- [ ] 后端模型是否与数据模型文档一致？
- [ ] API 返回字段是否能对应到数据模型？
- [ ] 是否更新 `docs/contracts/contract-map.md`？

## 5. 前端页面变更检查清单

- [ ] 是否更新 `docs/frontend/ui-spec.md`？
- [ ] 是否明确页面路径？
- [ ] 是否明确页面组件和状态？
- [ ] 是否明确表单字段和校验规则？
- [ ] 是否明确使用的 API？
- [ ] 是否处理加载态？
- [ ] 是否处理空状态？
- [ ] 是否处理错误态？
- [ ] 是否处理成功反馈？
- [ ] 字段是否与 API 文档一致？

## 6. 字段映射检查清单

- [ ] 是否更新 `docs/contracts/contract-map.md`？
- [ ] 同一业务含义是否只使用一套字段名？
- [ ] 前端字段是否与 API 字段一致？
- [ ] API 字段是否与后端字段一致？
- [ ] 后端字段是否与数据库字段一致？
- [ ] 不一致字段是否有明确说明？
- [ ] 是否存在文档中没有但代码中出现的字段？

## 7. 提交前检查清单

- [ ] 是否遵守 `R1`，只完成当前任务？
- [ ] 是否没有修改无关文件？
- [ ] 是否没有引入未确认依赖？
- [ ] 是否没有擅自改变技术栈？
- [ ] 是否已按 `R2` 更新相关文档？
- [ ] 是否已更新 `docs/tasks.md`，或是否已在变更摘要中说明任务状态？
- [ ] 是否已按 `R5` 运行测试或给出手动验证步骤？
- [ ] 是否已记录实际执行的验证命令？
- [ ] 是否已输出变更摘要？
- [ ] 是否存在未处理异常或错误状态？
- [ ] 是否存在文档和代码不一致？
- [ ] 如果修改了指南或模板，是否已运行 `npm run docs:check`？

## 8. 代码审查检查清单

- [ ] 是否符合 `requirements.md`？
- [ ] 是否符合当前功能文档？
- [ ] 是否符合 `api-spec.md`？
- [ ] 是否符合 `data-model.md`？
- [ ] 是否符合 `ui-spec.md`？
- [ ] 是否符合 `contract-map.md`？
- [ ] 是否有安全风险？
- [ ] 是否有未处理异常？
- [ ] 是否有重复实现？
- [ ] 是否缺少测试？
- [ ] 是否遗漏文档同步？
- [ ] 是否遗漏文档质量检查？

## 9. 安全敏感变更检查清单

- [ ] 是否已阅读 `project-kit/SECURITY.md`？
- [ ] 是否涉及认证、权限、密钥、支付、用户数据或数据删除？
- [ ] 是否已按 `R4` 让用户确认高风险变更？
- [ ] 是否没有提交真实密钥、Token、Cookie 或敏感样例数据？
- [ ] 是否更新环境变量、部署说明或安全审查文档？
- [ ] 是否验证未授权、越权、异常输入和错误响应？
- [ ] 是否说明数据迁移、删除或批量更新的回滚方案？

# 开发工作流

## 1. 项目初始化流程

```text
确认需求
→ 判断项目类型
→ 生成匹配文档
→ 初始化项目骨架
→ 运行验证
```

## 2. 功能开发流程

```text
阅读相关文档
→ 做功能影响分析
→ 更新必要文档
→ 修改代码
→ 添加或更新测试
→ 运行验证
→ 输出变更摘要
```

## 3. 文档更新流程

| 变更类型 | 必须更新的文档 | 验证方式 |
|---|---|---|
| 需求变更 | `docs/requirements.md` | 检查功能范围和非目标 |
| API 变更 | `docs/api/api-spec.md` | 检查前后端字段一致 |
| 数据库变更 | `docs/database/data-model.md` | 检查迁移和模型一致 |
| 页面变更 | `docs/frontend/ui-spec.md` | 检查页面状态和交互 |
| 字段变更 | `docs/contracts/contract-map.md` | 检查跨层字段映射 |

## 5. 任务状态更新流程

1. 开发前确认任务来源。
2. 开发中记录影响范围。
3. 完成后更新 `docs/tasks.md`。
4. 如果没有任务文档，在变更摘要中记录任务状态。

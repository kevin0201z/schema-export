# 安全策略

> AI 快速摘要
>
> - 适用场景：认证、权限、密钥、支付、用户数据、数据删除、部署安全等安全敏感变更。
> - 必须产出：风险点、待确认项、建议验证方式，必要时补充安全审查文档。
> - 硬性阻断：真实密钥、权限调整、支付、数据删除、生产部署等属于 Hard Stop。
> - 相关模板：`project-kit/templates/security-review.template.md`
> - 可跳过场景：普通文案修正、无安全含义的格式调整。

本文件定义 AI Project Guide 在处理安全相关任务时的仓库级规则。

## 1. 适用范围

以下变更必须视为安全敏感变更：

- 身份认证、登录、注册、会话、Token、OAuth
- 权限、角色、访问控制、多租户隔离
- 密钥、环境变量、证书、Webhook Secret
- 支付、订单、账单、发票
- 用户数据、隐私数据、日志数据
- 数据删除、批量更新、数据迁移和回滚
- 文件上传、下载、导入、导出
- 第三方服务集成
- 部署、网络、跨域、CSP、Cookie、安全响应头

普通任务不默认读取本文件。只有命中以上场景时，才进入本文件。

## 2. 与总控规则的关系

本文件承接 `project-kit/AI_PROJECT_GUIDE.md` 中的 `R4` 高风险确认。

涉及安全敏感变更时：

1. 先判断是 `Hard Stop` 还是 `Ask First`。
2. 先输出风险和待确认项，再决定是否继续。
3. 必要时补充 `project-kit/templates/security-review.template.md`。

## 3. 阻断分级

### Hard Stop

以下场景必须停止执行并等待确认：

- 修改认证、登录、会话或权限核心逻辑
- 修改支付、订单、账单或发票流程
- 删除用户数据、批量更新生产数据或执行不可逆迁移
- 写入、替换或暴露真实密钥、Token、Cookie、证书
- 修改生产部署、安全响应头、跨域、网络边界

输出格式：

```md
该任务属于 Hard Stop：

- 变更目标：
- 涉及的数据或权限：
- 风险点：
- 待确认项：
- 建议验证方式：

请确认后继续。
```

### Ask First

以下场景应先给出方案，再确认是否继续：

- 新增安全相关第三方服务
- 新增环境变量或密钥占位配置
- 调整上传、下载、导入、导出安全策略
- 修改日志脱敏、审计或安全检测逻辑

输出格式：

```md
该任务属于 Ask First：

- 变更内容：
- 影响范围：
- 推荐方案：
- 替代方案：

请确认采用哪种方案。
```

### Continue With Note

以下场景可以继续，但要在变更摘要中说明：

- 占位示例值调整
- 安全文档文案修正
- 不改变安全语义的格式整理

## 4. 密钥和环境变量

- 不得把真实密钥写入代码、文档、示例或日志。
- 示例密钥必须使用占位值，如 `YOUR_API_KEY`。
- 新增环境变量时，必须同步更新架构文档、部署说明和变更摘要。
- 日志中不得输出 Token、密码、验证码、Cookie、身份证件、银行卡等敏感信息。

## 5. 数据删除和迁移

涉及数据删除、结构迁移或批量更新时，必须明确：

- 影响的数据范围
- 是否可回滚
- 备份方案
- 验证方式
- 失败后的恢复步骤

数据删除、不可逆迁移和批量生产数据修改默认属于 `Hard Stop`。

## 6. 权限和访问控制

新增或修改权限时，必须明确：

- 角色列表
- 每个角色可访问的页面和 API
- 未授权访问的响应
- 越权访问测试场景

权限模型和访问控制调整默认属于 `Hard Stop`。

## 7. 安全验证清单

- [ ] 是否涉及认证、权限、密钥、支付或用户数据？
- [ ] 是否已按 `R4` 让用户确认高风险变更？
- [ ] 是否没有提交真实密钥或敏感数据？
- [ ] 是否更新环境变量说明？
- [ ] 是否验证未授权和越权场景？
- [ ] 是否验证异常流程和错误响应？
- [ ] 是否说明数据删除或迁移的回滚方案？

## 8. 漏洞反馈

本仓库尚未配置公开漏洞报告渠道。公开发布前，维护者应补充安全联系方式或私有报告方式。
